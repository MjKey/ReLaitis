**ReLaitis** - это полностью автономная (100% Local-First), высокопроизводительная и открытая платформа голосового управления компьютером и макросной автоматизации под Windows на базе **.NET 9** и современных Win32 API.

Проект создан как полноценный технологический преемник легендарного ассистента **Laitis** (v6.7.6.4), обладающий 100% функциональным паритетом, полной совместимостью с базами команд и макросов, но полностью освобожденный от устаревших внешних серверов и закрытого исходного кода.

---

## Ключевые возможности и преимущества

- **100% Local-First и конфиденциальность**: Никаких обязательных внешних серверов и облаков. Распознавание речи через Vosk и синтез речи через Windows SAPI работают полностью автономно без подключения к сети.
- **Мгновенный аппаратный ввод**: Эмуляция клавиатуры и мыши через низкоуровневый Win32 `SendInput` (задержка выполнения менее 1 мс).
- **Гибкие ключевые слова (Wake Words)**:
  - Поддержка любых ключевых слов через запятую: *«джарвис, слушай, эй ты, лэйтис, компьютер»*.
  - **Слитный ввод (в одно дыхание)**: *«Джарвис открой калькулятор»* - команда исполняется немедленно без пауз.
  - **Раздельный ввод**: *«Джарвис»* $\to$ звуковой сигнал $\to$ окно ожидания команды (6 секунд).
  - Быстрое голосовое глушение речи: фразы *«тихо»*, *«замолчи»*, *«стоп голос»* моментально обрывают синтез.
- **42 канонических типа действий**:
  - Запуск и завершение приложений, комбинации клавиш, ввод текста (включая Unicode и буфер обмена).
  - Умный клик по элементам интерфейса окон по их текстовому названию (Windows UI Automation).
  - Условия (`IfProcessSelected`, `IfProcessExists`, `IfVariableValue`), ветвления (`Else`), циклы (`Loop`, `While`, `Break`), случайные действия (`RandomActionBlock`).
  - Командные пакетные сценарии Windows Batch (`.bat`), HTTP-запросы, таймеры и расписание.
- **Голосовая мышь JetAim**: Управление курсором мыши голосом с помощью иерархической координатной сетки 3×3 (сектора 1..9, цепочки «528», клики по центру «выбрать», глубина до 5 уровней).
- **Плавающий ненавязчивый HUD**: Полупрозрачный оверлей громкости микрофона и распознанных слов, не перехватывающий фокус ввода у полноэкранных 3D-игр.
- **1-Click импорт из Laitis**: Автоматический поиск бэкапов в `%LOCALAPPDATA%\Laitis\SaveBackups` и прямая загрузка архивов `.laitis` и файлов `Save.json`.

## Структура решения

```
ReLaitis.sln
├── src/
│   ├── ReLaitis.Core        <-- Модели данных, ActionExecutor, VariableCalculator, CommandMatcher, LaitisImporter
│   ├── ReLaitis.Native      <-- Win32 SendInput, трекер окон, глобальные хоткеи, UI Automation
│   ├── ReLaitis.Audio       <-- Захват NAudio, STT (Vosk/Google/SAPI/Whisper), TTS (Edge/Google/SAPI), Coordinator
│   └── ReLaitis.UI          <-- WPF Fluent UI, главное окно, HUD, JetAim оверлей, диалоги
└── tests/
    └── ReLaitis.Tests       <-- 64 модульных теста на xUnit и FluentAssertions (100% passing)
```

## Быстрый старт

### Системные требования:
* Windows 10 (1903+) / Windows 11 (x64)
* [.NET 9.0 Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/9.0)

### Запуск готового приложения:
Запустите `Run-ReLaitis.cmd` или `ReLaitis.UI.exe` в папке с приложением.

### Сборка из исходного кода:
```powershell
# Сборка решения в конфигурации Release
dotnet build -c Release

# Запуск тестов
dotnet test -c Release --verbosity normal

# Запуск WPF-приложения
dotnet run --project src/ReLaitis.UI/ReLaitis.UI.csproj -c Release
```
