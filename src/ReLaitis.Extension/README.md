# ReLaitis Voice Bridge (Расширение для Chrome / Edge / Яндекс.Браузера)

Официальное браузерное расширение для голосового управления страницами в **ReLaitis** (Manifest V3).

## Возможности
- 🎯 **Умные бейджи интерактивных элементов:** по команде *«Ссылки»* или *«Покажи ссылки»* на всех кнопках, ссылках и полях ввода появляются номера.
- 🗣 **Голосовые клики:** скажите *«Клик 12»* или *«Нажми 5»*, чтобы мгновенно кликнуть нужный элемент.
- 📜 **Плавный скролл:** *«Страница вниз»*, *«Страница вверх»*, *«В самый верх»*, *«В самый низ»*.
- 📑 **Управление вкладками:** *«Новая вкладка»*, *«Закрыть вкладку»*, *«Следующая вкладка»*, *«Предыдущая вкладка»*, *«Обновить страницу»*.
- 🌐 **Двусторонний WebSocket:** авто-переподключение к локальному серверу ReLaitis (`127.0.0.1:11337`).

---

## Инструкция по установке

### В Google Chrome / Яндекс.Браузере:
1. Откройте страницу расширений: введите в адресной строке `chrome://extensions` (или `browser://extensions`).
2. В правом верхнем углу включите переключатель **«Режим разработчика»** (Developer mode).
3. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked).
4. Выберите папку:
   `c:\Users\mjkey\Desktop\ReLaitis\src\ReLaitis.Extension`
5. Расширение **ReLaitis Voice Bridge** появится в списке и автоматически подключится к запущенному ReLaitis.

### В Microsoft Edge:
1. Откройте `edge://extensions`.
2. В левом меню включите **«Режим разработчика»**.
3. Нажмите **«Загрузить распакованное»** и выберите эту же папку.
